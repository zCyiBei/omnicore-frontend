## Prerequisites

* **Node.js** (v18.0.0+)
* **npm** (v9.0.0+)

## Setup

1. Clone repository:
```bash
git clone https://github.com
cd omnicore-frontend
```

2. Install dependencies:
```bash
npm install
```

3. Run development server:
```bash
npm run dev
```
